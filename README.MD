# Proyecto: QuickOrder

> **Nota:** Para contribuir en proyecto, es importante que lea el documento [CONTRIBUTING.MD](https://github.com/joaquin-ossandon/quickorder-js-fullstack/tree/dev?tab=contributing-ov-file) que está en este mismo repositorio.

## ¿Qué es QuickOrder?

Crearemos una aplicación FullStack para un restaurante que permitirá a los clientes:

- Explorar un Menú Digital categorizado. (Front-End)
- Añadir y gestionar productos en un carrito de compras. (Front-End)
- Finalizar un pedido que se almacena en una Base de Datos. (Back-End) (🚫SIN INTEGRACIÓN DE PAGO)
- Contar con un Panel de Administración para gestionar el menú y ver los pedidos. (Front-End y Back-End)
